# Learnings

What past runs of this skill found out about **running the interview**. The skill reads this file at the start of every session and appends one entry at the end (`SKILL.md`, Step 7).

**Never write anything about the user's life here.** This file lives in a public repo. Write about the questions, the pacing and the drafting, not about the person.

When the same signal shows up three or more times, it's a pattern: propose a concrete edit to `SKILL.md` or `references/question-bank.md`, apply it only if the user agrees, and mark the entries here as `→ promoted`.

## Entry format

```
### YYYY-MM-DD · first-run | refresh · N questions · ~M min
- Strong: <question or move that landed, and the signal>
- Weak: <question or move that fell flat, and the signal>
- Correction: <what I assumed → what was true>
- Missed: <something the user volunteered that no question reached>
- Change: <what the user said they'd change, if anything>
```

Leave out lines that have nothing in them.
